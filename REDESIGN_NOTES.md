# BrewAI visual redesign

This build redesigns the exact uploaded BrewAI_Final_Corrected codebase without changing the core ordering/database architecture.

## Visual changes
- Editorial espresso/cream customer design
- Sticky glass navigation with scroll state and page progress
- Responsive mobile navigation
- IntersectionObserver scroll-reveal animation
- Hero image depth/parallax effect
- Animated marquee, AI visualization, rewards cards and micro-interactions
- Redesigned menu cards and customization modal styling
- Redesigned Chef kitchen display
- Separate redesigned Chef and Admin login experiences
- Redesigned Admin operations dashboard
- `prefers-reduced-motion` support

## Images
Place the existing product JPGs in `static/images/` using the filenames in `IMAGE_FILENAMES.txt`.
